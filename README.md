# Assignments for EAPS 507 – Fall 2026

This repository contains my Jupyter notebook assignments and in-class exercises for EAPS 507 (Fall 2026). The notebooks cover Python fundamentals, numerical calculations, and data analysis with pandas and xarray.

## Assignments

| Notebook | What it covers |
| --- | --- |
| [Assignment 1 – Madhava-Leibniz Pi Calculation](Assignment_1_Madhava_Leibniz_Pi.ipynb) | Approximating pi with the Madhava-Leibniz series, tracking and plotting absolute error, and writing reusable Python functions. |
| [Python Refresher – Functions and Scope](Python_Refresher_Functions_and_Scope.ipynb) | Fixing a recursive factorial function, defining functions, and exploring local and global scope. |
| [Pandas – Earth Science Data Manipulation](Pandas_Earth_Science_Data_Manipulation.ipynb) | Loading and inspecting Indiana geographic features data, exploring DataFrames, and practicing data manipulation in pandas. |
| [Xarray – Beginner Tutorial](Xarray_Beginner_Tutorial.ipynb) | Working with labeled multidimensional data, DataArray and Dataset objects, selections, calculations, and plots. |

## Running the notebooks

The `.ipynb` files can be viewed on GitHub or opened in Jupyter Notebook or JupyterLab. Python libraries used across the notebooks include NumPy, pandas, Matplotlib, and xarray.

**Dataset note:** The Pandas exercise refers to `IN_Features_20140204.txt`. This dataset is not included among the uploaded notebooks. To rerun cells that read it, place the dataset in the notebook's working directory.
